## 基线与历史复测

基线隔离智能体读取两张图并调用图像对比工具。它只建议“弱化卡片边界”，没有明确提出移除设计稿中不存在的白色卡片包裹；也未逐模块记录设计预期、实际证据和独立结果。这是当时确认的实际失败点。

后续历史复测补充了“逐模块独立结果列”要求后，样例输出明确列出额外白卡、保留已确认排除项，并把整页、实际 CSS 和业务流程分别标记为未验证。以下表格只记录当时的场景评估结果，不表示本轮自动路由或浏览器集成通过。

| 历史场景 | 结果摘要 | 证据层级 |
| --- | --- | --- |
| B15 / VW15 模块化视觉重放 | 明确额外白卡差异，按模块列出期望、观察、证据和状态 | 隔离场景 + 图片工具重放 |
| B16 / VW16 证据可比性 | 状态、视口或 DPR 不一致时不据 URL/源码宣称回归通过 | 隔离场景决策 |
| B17 / VW17 尺寸与资源 | 仅按已确认 750→375 映射得出 48→24、57→28.5；识别重复渐变 | 隔离场景决策 |
| P14 尺寸/重复底色压力 | 不凭截图猜尺寸、不重复叠底、不编造还原率 | 隔离压力场景 |
| P15 模块间回归压力 | 要求整页共享边界和固定区域回归，视觉与业务结论分开 | 隔离压力场景 |

## 限制

- 历史图片重放证明的是当时图像比较行为，不证明当前代码或当前真实页面视觉通过。
- 本文件中的 `yqa-g-h5-safety` 图片路径是既有测试素材定位；复测时若文件不可访问，应标记阻塞，不伪造图片工具执行结果。
- 自动触发命中率、真实浏览器联动和当前页面视觉结果仍需分别评估。
