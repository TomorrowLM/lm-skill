# 项目配置类场景 token 优化

## AGENTS / 规范模板生成

**步骤：**

1. 只读取当前项目命中的技术栈模块（如项目用了 React + Tailwind，只读这两个模块的规范）。
2. 默认保留规则文本，示例代码、完整目录树和清单明细按需展开。
3. 不在多项目 workspace 中为所有项目生成 AGENTS。

**常见陷阱：**

- 读取所有技术栈的完整规范模板，"以防用户以后需要"。
- 生成 AGENTS 时附带完整示例代码和目录树。

## 公共组件 / 公共资源复用

**步骤：**

1. 先读当前项目 AGENTS.md 中的组件清单和公共资源清单。
2. 清单中有匹配的就直接复用，不再扫描目录。
3. 清单缺失、疑似过期或需要新增/调整时，才最小范围扫描对应目录。

**常见陷阱：**

- 每次开发都全量扫描 `src/components/` 目录。
- 清单已有匹配组件，仍然读组件源码来"确认"。

## 多项目 Workspace

**步骤：**

1. 只读取当前上下文明确涉及的项目，不扫描所有项目。
2. 在 workspace 中跨项目引用时，只读目标项目的 AGENTS.md 和关键文件。
3. 不为了"保险"预加载所有项目的 AGENTS。

**常见陷阱：**

- 打开一个项目的文件后，顺手读取同 workspace 其他项目的同类文件。
- 为所有项目生成或更新 AGENTS，而不是只处理当前涉及的。
