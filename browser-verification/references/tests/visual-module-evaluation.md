## 基线：真实图片任务

独立智能体未加载目标技能或草稿，实际读取两图并调用图像对比工具。用户任务为：对比图片，给出可交给开发的样式建议；已确认的 Tab 和入口变更不得报错。

原始关键回答：

> 当前图增加了圆角白卡包裹，与设计图的开放式信息区层级不同。建议弱化卡片边界。

观察到的失败：B15 需要明确识别和处理额外白卡，而该建议仍允许保留白底包裹；各模块也没有完整记录设计期望、实际证据与独立状态。实际读取路径和工具动作与 B15 fixtures 对应。

基线并非完全错误：它保留了已确认的排除项，没有虚构精确 CSS 数值，也没有声明业务通过。此次只针对实际缺口补规则。

2. 增补“独立结果列”规则及 B15 断言；静态检查确认二者同步。

4. 另一隔离智能体执行八项受控场景。它没有操作浏览器或修改文件；返回的是场景决策，不是实际页面执行成功证据。
