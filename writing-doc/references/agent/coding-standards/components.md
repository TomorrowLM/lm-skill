# 项目公共组件

## 组件复用原则

1. **优先使用已有公共组件**，不要重复实现已有功能
2. **新增公共组件前先检查 `src/components/`** 是否已有类似组件
3. **公共组件必须有中文注释**，说明用途、Props 和使用场景
4. **组件必须放在独立文件夹内**，包含 `index.tsx` 和 `types.ts`
5. 项目已有图标封装组件时，SVG 图标优先通过该组件统一展示；未封装时按当前 UI 库图标方案使用

## 新增公共组件规范

1. 组件必须是**多页面复用**的，单页面使用不提取为公共组件
2. 组件文件夹使用大驼峰命名，主文件命名为 `index.tsx`
3. 类型定义放在同目录的 `types.ts`
4. 样式文件放在同目录（按项目样式方案命名）
5. 组件必须写 JSDoc 注释说明用途和使用场景
