# UI 与交互规范

## 状态与反馈

1. 组件和页面需覆盖加载、空、错误、成功等用户可感知状态
2. 数据为空时统一显示 `--`，列表或内容区域需提供明确的空状态
3. 提交类交互需防止重复提交，危险操作必须进行二次确认
4. 操作失败时提供明确反馈，接口请求失败提示由请求层统一处理，业务代码不重复提示

## 图片展示

1. 所有图片展示必须支持点击预览，点击图片可查看原图大图
2. 统一使用 `FileView` 或 `ImagePreview` 组件实现图片预览，保证预览体验一致
3. 图片必须添加有意义的 `alt` 属性
4. 图片加载失败需显示兜底占位图，不展示裂图

## 交互实现

1. 输入框、按钮等可操作元素按项目测试规范添加测试标识
2. 交互状态和反馈应与用户操作保持一致，避免无反馈、重复反馈或阻塞后续操作
